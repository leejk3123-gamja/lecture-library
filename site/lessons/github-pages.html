GitHub로 자료실 운영하기

2026.10.29 · 공개 자료실 운영 입문

운영 체크리스트

1. 파일 준비

강의 본문은 lessons에, 내려받을 파일은 materials에 둡니다. 홈페이지 목록 정보는 assets/materials.js에서 관리합니다.

2. 게시

저장소에 변경 내용을 커밋하면 GitHub Actions가 정적 파일을 검사한 후 Pages로 게시합니다. Settings → Pages에서 Source를 GitHub Actions로 설정해야 합니다.

3. 확인

  • 홈페이지에서 새 강의가 검색되는지 확인합니다.
  • 강의 링크와 다운로드를 직접 열어 봅니다.
  • 휴대전화 화면에서 본문과 파일이 읽히는지 확인합니다.

4. 공개 범위

이 예제에는 로그인이나 비공개 자료 기능이 없습니다. 공개해도 되는 자료만 올리며, 사용자 정보나 비밀번호를 저장하지 않습니다.
